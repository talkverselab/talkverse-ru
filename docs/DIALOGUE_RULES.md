# 회화 규칙 — 러시아어 특이점

공통 원칙(사용자 결정 2026-11-02): https://talkverse.uk/talkverse/dialogue-rules/ · 절벽 기준표: https://talkverse.uk/cliff/18/
회화를 만들거나 고칠 때는 위 원칙을 따른다. 이 문서에는 **러시아어만의 특이점**만 적는다.

## 1. 절벽 구간 (레벨)
R1 156 · R2 누적 251 · R3 누적 685 · R4 누적 1,985 lemma(회화 커버리지 55/60/70/80%).
어휘 상한 = 그 구간까지의 누적 lemma.

## 2. 턴 길이
- 단위는 **단어 수**(하이픈 단어는 1개, 문장부호 제외).
- R1 은 턴마다 **3단어 이상**(단답 금지 — 「Да.」·「Нет.」 단독 불가). R2 이상은 길이 제한 없음, 자연스러운 길이.

## 3. 읽기 표기 (rd)
- 러시아어 본문(tl)에는 **강세 부호(◌́)를 단다**(단음절어 제외). 독음은 강세 모음을 기준으로 적고, 비강세 о 는 「아」로 읽는다(모스크바식 아깐예).
- 표기 예(현재 데이터 관례): Приве́т → 쁘리볱 · отку́да → 아꾸다 · спаси́бо → 스빠씨바.
- **할 일**: 자음·모음 대응표를 정하고 스크립트로 검사한다. 지금 데이터는 표 없이 손으로 단 독음이라 들쭉날쭉할 수 있다.

## 4. 기본 변이
표준 러시아어(모스크바, `ru_RU`) 하나. 다른 변이는 만들지 않는다.

## 5. 성별판 — 필요함
러시아어는 **화자 성별에 따라 말이 바뀐다**: 과거형 동사(я был / была, сказа́л / сказа́ла), 단어미 형용사(рад / ра́да, гото́в / гото́ва, уве́рен / уве́рена), 일부 명사·호칭.
→ 학습자(A) 성별판을 규칙 치환으로 만든다. 치환 규칙과 파일 이름은 아직 정하지 않음(할 일).
지금 데이터의 A(Daniel)는 남성형으로만 쓰여 있다.

## 6. 지금 데이터와 원칙의 차이 (할 일)
- `assets/data/dialogues/L1.json` 18편·144턴은 **L1 표기** → 어휘 상한 기준으로 R 값을 다시 매겨야 한다(원칙 §2).
- 모든 편이 8턴 → R2 이상으로 판정되면 턴 수 기준(8~12, 12~16)을 다시 확인한다.
- 말투: 전부 ты(반말). 챗앱에서 처음 만난 사이라 원칙 §5(낯선 사이 = 존댓말 вы)와 어긋날 수 있다 → 검토할 것.
- 반전: 18편 모두 1회, `twist` 태그로 표시돼 있음 — 원칙과 맞음.
- `purpose[]`·`domain[]`·`flags[]` 태그가 없음. 검수 기록(자동 검사·Grok·Gemini)과 `draft` 태그도 없음.
- B 가 「현지인」으로 이름이 없음.
