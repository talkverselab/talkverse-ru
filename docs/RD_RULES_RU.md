# 러시아어 한글 독음(rd) 표기표 — 2026-11-07 v1

변환기 `tools/rd_ru.py`, 검사 `tools/check_dialogues.py --fix-rd`. 원칙 = 소리 나는 대로, 강세 부호를 기준으로 적는다. 손으로 고친 턴은 `rd_manual: true`.

| 구분 | 표기 |
|---|---|
| 된소리 | к ㄲ · п ㅃ · т ㄸ · ц ㅉ (예: Приве́т 쁘리볱) |
| 예사소리 | б·в ㅂ · г ㄱ · д ㄷ · ж·з ㅈ · ф ㅍ · х ㅎ · ч ㅊ |
| 치찰음 | с ㅅ(си 씨) · ш·щ 시 계열(шо 쇼) |
| 연음 | те·ти 찌 계열 · де·ди 지 계열 |
| 비강세 모음 | о → 아 · е·я → 이(낱말 끝 я 는 야) |
| 낱말 끝 | т·д ㅌ받침 · к·г ㄱ받침 · п·б ㅂ받침 · м ㅁ · н ㄴ · л ㄹ · в 프 · с·з 스 · ш·ж 시 |
| 겹자음 앞 | 무성음 앞의 유성음은 무성으로(всё 프쇼) |
| 어미 | -ого·-его → 보 계열 · -ться·-тся → 짜 · -ся → 샤 · -ий·-ый → 이·의 |
| 뒷말에 붙는 말 | не·ни 니 · на 나 · по 빠 · в 브 · с 스 · к 끄 등 강세 없음(`CLITIC`) |
| 예외 낱말 | что 시또 · сего́дня 시보드냐 · спаси́бо 스빠씨바 · конечно 까녜시나 등(`RESPELL`) |

문장부호는 적지 않는다. `{name}` 같은 변수는 그대로 둔다. 기존 `L1.json` 독음은 손으로 달아 이 표와 다를 수 있다.
