# 러시아어유니버스 (russian_universe)

opus_ru 자국 코퍼스(3,589 자막·1,303만 토큰) 기반의 한국 화자 러시아어 학습 앱.

## 설계 명제 (spec 요지)

**약 300단어(R1 156 + R2 95 + 불규칙 인칭형)로 러시아어 문법 시스템 한 바퀴가 닫힌다.** 이 지점이 토큰 커버율 약 60%와 거의 일치 — "문법 골격 완성 = 회화 절반 커버"가 같은 지점에서 만난다.

### 관통하는 철학 — "한 번에 하나, 나머지는 흘린다"
- 발음: 결과(소리)만 노출, 규칙 설명은 숨김 (인지하는 순간 무너진다)
- 동사: 과거형(쉬움) 먼저, 현재 불규칙은 통문장으로
- 격: 대→생→여 먼저, 조·전치격은 나중
- 단어: 코어 40 vs 확장 110 — 로직 반복은 코어 40만 닳도록
- 반복: 단어가 아니라 **10단계 로직**에 걸기

### 트랙 분리
- **트랙 A** = 규칙 엔진 (불규칙 0% 섞기, 로직·라임 학습)
- **트랙 B** = 불규칙 통문장 ("Я хочу́ есть" — 표가 아니라 문장으로)

## 구조

### A. 알파벳 단계 (~50 내용어)
- 1군 영어와 동일 (А К М О Т) → 2군 false friend (В Н Р С У Х) → 3군 새 글자
- 발음규칙은 **플래시카드에 묻어서** (단원으로 만들지 않음) — друг [드루크], молоко́ [말라코]

### B. 문법 단계 — 10단계 선형 커리큘럼
1. 형용사 + 명사 (주격)
2. 주어 + 과거동사 + 형명 + **가정법(과거+бы)**  ← 가정법 합류
3. 주어 + 과거동사 + 형명(대/여/생격)
3'. 주어 + 과거동사 + 형명 + [전치사+격] ← с+조격(동반)
4. 주어 + 일반동사(1식/2식) + 형명 + 전치사구 ← 단수 3인칭만
4'. 조격 단독 — 도구·신분·быть 보어
5. 불규칙 동사 (통문장, 트랙 B)
6. вид(상) + 미래 — 동사 짝 1개로 시제·상 통합 시연

### 단수 3인칭 우선 정책
- 동사·과거형·양태 모두 я / ты / он(она́) 3인칭만 깐다
- 복수(мы/вы/они́)는 레벨 잠금 → 단수 완성 후 해금
- 명사 복수 불규칙(друзья́/де́ти/лю́ди)도 함께 미뤄짐

### 선형 잠금
R1까지(150) 순서 강제, 이탈 불가. R1 이후는 자유.

## 데이터 산출물 (구현 시 필요)

1. **전치사→격 매핑** — `analysis_domestic/prep_case.csv` 활용
2. **동사→격 지배 사전** (신규 — 30개로 회화 대부분 커버)
3. **명사 굴절 엔진**: `(격, 성, 변화형) → 어미`
4. **동사 변화 엔진**: 규칙(1식/2식) + 불규칙(통문장)
5. **플래시카드**: 앞=키릴 / 뒤=소리+뜻 (규칙설명은 접힌 선택)

## CEFR 위치
- 어휘량: A1 미만~A1 (R1+R2 230 lemma)
- 문법 도달: **A2~B1 관통** (격 6·1·2식·양태·전치사·상 입문·가정법)
- 일반 교재의 정반대: **어휘 최소화 + 문법 골격 선취**. 어휘는 연수에서 채움.

## 한국인 관점 재배분
- 격은 한국어 조사와 1:1 → 거의 공짜
- 어순 자유 → 한국어와 동일 (SVO 기본)
- 관사 없음 → 영어 a/the 지옥 없음
- 진짜 부담은 **вид(상) 하나** — 현지 듣기로 떠넘김
