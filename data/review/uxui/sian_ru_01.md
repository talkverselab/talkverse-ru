# 러시아어앱 UX/UI 시안 01 (2026-11-03, 세션 직접 작성)

기본 구조 = 일본어앱 시안 02(장면 컷이 주인공, 왼쪽 레일 + 두 칸, 하단 컨트롤, 오늘의 컷, 「나」 탭 성과)를 **그대로** 쓴다.
러시아어의 강점이 드러나는 칸 **두 개만** 더한다. 인물은 통과된 캐릭터 시트(`data/review/art/chars_ru_v1.jpg`, `CHARACTERS.md`).

## 1. 앱 한 줄 소개와 러시아어의 강점
- 한국 화자를 위한 러시아어 회화 앱. 채팅앱에서 처음 만난 현지인(아냐)과의 대화로 시작한다.
- 강점 ① **격 = 한국어 조사.** 러시아어 명사 끝(어미)이 바뀌는 자리는 한국어의 「은/는·을/를·에게·에서」와 1:1로 대응한다. 끝을 색으로 칠하고 조사를 붙여 보여 주면 「영어보다 쉽다」는 걸 바로 느낀다.
- 강점 ② **강세 + 한글 독음.** 러시아어는 강세 자리가 정해져 있지 않고, 강세가 없는 о 는 「아」로 읽는다. 강세 모음을 굵게 칠하고 한글 독음을 함께 붙이면 키릴 문자를 몰라도 첫날부터 소리 낼 수 있다.

## 2. 더하는 칸 (시안 02 위에 두 개만)
### A. 자막 토글에 「격」 단계 추가
하단 자막 토글 = `Русский / 강세 / 독음 / 격 / 한국어`.
「격」을 켜면 스크립트와 말풍선에서 명사·형용사의 어미에 격 색을 칠하고, 그 아래에 작은 한국어 조사 표시를 붙인다.
격 색(6격, 톤 안에서 채도 낮게): 주격 남색 · 생격 하늘색 `#5AA9E6` · 여격 인디고 `#635BFF` · 대격 청록 · 조격 회청 · 전치격 연보라.

```
┌ 스크립트 한 줄 (격 켬) ───────────────────────────┐
│ 3  Я живу́ в Москв[е́]                    🔊     │
│                  └ 전치격 · ~에서               │
│    야 쥐부 브 마스크볘 · 나는 모스크바에 살아      │
└──────────────────────────────────────────────┘
```

### B. 오른쪽 아래 「말 조각」 카드 (현재 문장 카드 자리 확장)
지금 재생 중인 문장의 단어를 탭하면 카드가 바뀐다: 기본형(사전형) · 이번에 바뀐 끝 · 같은 단어 다른 격 2~3개 · 단어 그림 1장.

```
┌ 말 조각 ───────────────────────────────┐
│ [그림: 도시]  Москва́ → в Москв[е́]      │
│              모스크바 → 모스크바에서     │
│  다른 모양: Москв[у́](를) · Москв[ы́](의) │
└───────────────────────────────────────┘
```

## 3. 화면 (아이패드 가로, 4:3)
### 모든 문장 듣기 — 그림으로 그릴 화면
```
┌──────────┬───────────────────────────┬───────────────────────────────┐
│ 레일     │ 대화 스크립트         ⑧   │ 회화 장면                      │
│ 배우기●  │ 1 Приве́т! А ты отку́да? ●  │ ┌ 장면 컷 (주인공, 점토풍) ──┐ │

│          │ 3 Я живу́ в Москве́.         │ └───────────────────────────┘ │
│          │ ...                       │ ┌ 말 조각 ─────────────────┐ │

│          │                           │ └───────────────────────────┘ │
```

### 「나」 탭 성과
```
┌ 성과 ─────────────────────────────────────────────┐
│ 커버율: 내가 아는 단어로 일상 러시아어의 31% 이해   │
│ 격 지도: 6격 중 익힌 격 ●●●○○○                      │
│ 주제별 진행 막대 · 구간(R1~R4)별 완주 수 · 복습 단계 │
└─────────────────────────────────────────────────┘
```
세는 것: 편 완주, 복습 단계 상승·졸업, 「격」 단계에서 맞힌 끝, 커버율.
세지 않는 것: 앱 연 횟수, 연속 일수, 포인트, 순위.
